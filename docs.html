Kernel Pulse Docs

The open-source, serverless status page for your infrastructure.

What is Kernel Pulse?

Kernel Pulse is a lightweight status monitoring tool developed by Kernel Kernel. Unlike traditional status pages that require a backend server and database, Pulse runs entirely in the browser (Client-Side).

It provides real-time connectivity checks for your websites, APIs, and services without costing a penny in hosting fees.

How to Use (For Users)

Simply visit the dashboard. The system automatically performs a "Health Check" on all configured services.

Understanding the Badges:

  • ONLINE: The service is reachable.
  • OFFLINE: The service is unreachable.
  • WAITING: The system is currently pinging the server.

Auto-Refresh

Toggle the "Auto-Refresh" switch in the sidebar to keep monitoring in the background. This updates the status every 30 seconds automatically.

Developer Guide: Create Your Own

You can fork Kernel Pulse to create a status page for your own projects. It is free and open-source.

1

Fork the Repository

Go to GitHub and fork the Kernel Pulse repository to your own account.

2

Edit Configuration

Open config.json in the root folder. Replace the example services with your own:

{
  "brand": {
    "name": "My Status Page",
    "parent": "My Company"
  },
  "categories": [
    {
      "name": "My Projects",
      "services": [
        { 
          "id": "portfolio", 
          "name": "Portfolio", 
          "url": "https://mywebsite.com", 
          "desc": "Personal Site" 
        }
      ]
    }
  ]
}
3

Deploy

Connect your GitHub repository to Vercel, Netlify, or GitHub Pages. The app works instantly without any build steps.
